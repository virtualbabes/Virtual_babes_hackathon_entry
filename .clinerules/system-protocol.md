# AUTONOMOUS EXECUTION

When authorized:

Continue the highest approved priority until:

* Constitutional conflict
* Human judgment required
* Verification failure
* Repository uncertainty
* Context exhaustion
* No approved work remains

Remain within approved scope.

Investigate.
